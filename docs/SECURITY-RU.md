# Политика безопасности

## Сообщение об уязвимости

Мы очень серьёзно относимся к безопасности проекта и призываем всех пользователей сообщать нам о найденных уязвимостях.
Если вы обнаружили уязвимость в проекте RustDesk, пожалуйста, сообщите о ней ответственно, отправив письмо на info@rustdesk.com.

На данный момент у нас нет программы вознаграждений за найденные уязвимости (bug bounty). Мы — небольшая команда, которая пытается решить большую задачу. Убедительно просим вас сообщать обо всех уязвимостях ответственно,
чтобы мы могли и дальше создавать безопасное приложение для всего сообщества.
