# 竞品参考：向日葵（贝锐）控制端 Android 版功能流程

> 来源：<https://service.oray.com/question/16428.html>（官方帮助文档，更新于 2026-02-11）。
> 目的：作为 OHOS 主控端后续迭代的功能/交互参考。逐项对照基于
> `m1-controller-status.md` 的 M1/M2 现状与 `RemotePage.ets` 当前实现（2026-10-26）。

## 一、向日葵控制端功能全景

### 1. 账号与设备管理（首页层）
- 登录五种方式：手机验证码免密、本机一键登录（运营商）、贝锐账号、微信、企业账号；
  未注册自动创建 `orkj` 前缀账号。
- 设备列表：>4 台可按名称/在线优先排序；模糊搜索；最近远控记录。
- 添加设备：添加电脑主机 / 控制移动设备 / 扫一扫 / 智能硬件；企业可用识别码
  或"生成主机"（填名称备注得葵码，被控端用葵码登录即绑定）。
- 设备功能按**被控系统差异化**展示：
  Windows（桌面控制/观看、摄像头、远程文件、CMD、关机重启）、
  macOS（无摄像头）、Linux（+SSH）、Android（桌面/摄像头/文件）、iOS（仅桌面）。
- 设备设置：改名、复制葵码、绑域名、上下线提醒、定时开机（需开机硬件）。

### 2. 远协（识别码连接）
- 输入远端识别码发起；**验证码选填、密文显示**（眼睛图标切换明文）。
- 成功连接后**自动记录验证码**，下次自动填充。
- 不填验证码 → 需远端人工同意。

### 3. 手机投屏（三种发起方式）
对端输入投屏识别码+验证码 / 扫个人版投屏码 / 向账号下在线设备发起。

### 4. 远程工具栏（远控桌面内，右下角 `<>` 呼出）
| 分组 | 功能项 |
|------|--------|
| 远控键盘 | 文字输入；16 个预设快捷键（Ctrl+C、Win+Tab、Ctrl+Shift+Esc…）；**自定义组合键最多 5 个** |
| 快捷操作 | 切换屏幕、**录像、截屏、声音开关、锁定桌面、黑屏（隐私）、旋转屏幕、关机/重启** |
| 远控方式 | 指针/触摸模式、虚拟鼠标 |
| 远控质量 | **显示诊断（速度/延迟/帧率）**、切换转发、隐藏背景 |
| 桌面模式 | 高清 / 游戏 / **极速（黑白画面，弱网友好）** |

### 5. 其他入口
桌面观看、摄像头、远程文件、CMD 命令行；游戏键盘（游戏版专属，横屏，
按键类型/大小/按压方式/最多 10 键连击/透明度/分享）。

### 6. 注意事项（原文）
- 被控端**不知悉**控制端在录像/截屏（RustDesk 语义不同：被控端有提示，不必跟随）。
- 硬解码建议开启，出现花屏则关闭（排障引导）。
- 移动网络远控耗流量大，建议开启**移动网络二次确认提醒**。
- 已分享的游戏键盘不可直接编辑，需先取消分享。

| 远端光标 / 虚拟鼠标 | 光标开关 ✅；指针/触摸模式互斥 ✅ | ✅ 已有 |

| 文字输入 | 键盘输入条 ✅ | ✅ 已有 |

## 三、交互流程借鉴（不涉及新协议）

1. **验证码/密码自动回填**：向日葵成功后自动记录验证码；我们已有"记住密码"，
   可对齐为"连接成功后默认勾选 + 下次自动填充"。
2. **移动网络二次确认**：连接建立时检测网络类型，蜂窝网络弹一次确认（记住选择）。
   OHOS 侧 `@ohos.telephony.radio` / `@ohos.net.connection` 可取网络类型。
3. **硬解花屏排障引导**：解码异常（花屏反馈）时提示"可切换软解"，
   直达显示设置的编解码偏好。
4. **密文验证码 + 眼睛切换**：密码输入框已用 `InputType.Password`，无需改。

## 四、落地优先级建议

- **P1（纯桥接/小改，Session 能力现成）**：静音开关、隐私黑屏、重启/关机、
  截屏（需实现 `handle_screenshot_resp` → 图库/文件）、显示诊断浮层。
- **P2**：预设快捷键扩充、旋转屏幕、自定义组合键（需 preferences 持久化）。
- **P3/观察**：极速黑白画质档、CMD、游戏键盘（远控游戏场景，工作量大）。
- 落地时逐项核对 `ohos_ffi.rs` 事件转发是否覆盖对应回调
  （如 `update_privacy_mode`、connection stats、screenshot resp）。
